# Chemistry, Elements & Materials Knowledge Corpus

An atom is a microscopic particle.
A molecule is a microscopic particle.
An atom is part of a molecule.
A molecule is part of matter.

Gold is a metal.
Silver is a metal.
Iron is a metal.
Copper is a metal.
A metal is a solid.

Carbon is an element.
Hydrogen is an element.
Nitrogen is an element.
An element is a chemical substance.

Water is a chemical compound.
A chemical compound is a chemical substance.
A chemical substance is matter.
